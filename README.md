# AR4 3D-Printer Automation

Automates a fleet of Bambu Lab A1 Mini printers with an Annin AR4 robot arm
(ROS 2 + MoveIt2): the arm scans ArUco markers to locate each printer, scrapes
finished prints off the build plate, and cycles the print queue.

## Repository layout

```

runScrapePlate.py, runDoubleTransfer.py,
scanFor2Markers.py, scanFor3Markers.py

                                 client), printer_automation (robot node),
                                 aruco_detector, pose_reader, camera stack,

                                 joint monitor, plotting, object generator).

                                 calibration, wifi hotspot for the printers).
```

Run entry points from the repo root, e.g. `python3 runScrapePlate.py`.
Scripts in `calibration/`, `tools/`, and `archive/` bootstrap `sys.path`
themselves and can be run from anywhere.

## Testing in Gazebo

Most entry points have a sim switch at the top of the file — `RUN_SIM = 1` in
`runScrapePlate.py` / `runDoubleTransfer.py`, `runVirtual = 1` in the
`scanForNMarkers` scripts — to run against the simulator instead of the
physical robot: the camera feed comes from the simulated RGBD camera
(`/rgbd_camera/image` + `camera_info`, bridged by `annin_ar4_gazebo`), and
simulated printers are spawned in the scene in place of the hardware save file.

```bash
./scripts/launchVirtualRobot.sh        # Gazebo + MoveIt (wait until loaded)
python3 runScrapePlate.py              # markers 1, 2   (with RUN_SIM = 1)
python3 runDoubleTransfer.py           # markers 0, 1, 2 (with RUN_SIM = 1)
python3 scanFor2Markers.py             # interactive menu (with runVirtual = 1)
python3 scanFor3Markers.py
```

The gripper is disabled in sim (physics instability), and the webcam-specific
settings (90° feed rotation, distance-scale correction, `camera_matrix.npz`)
don't apply — intrinsics come from the sim camera's `camera_info`.
`runFullAutomationWithScrape.py` has no `--sim` mode: it drives a real Bambu
printer over MQTT/FTPS, which has no simulated counterpart.

# BambuPrinter Python Client

A Python client for **local network control of Bambu Lab 3D printers** using **MQTT** and **implicit FTPS**.

This project allows you to:

- Control prints (start, pause, stop, home)

- Send raw G-code commands

- Monitor live printer status (progress, temperatures, layers, state)

- Upload and list files on the printer’s SD card

- Register callbacks for print completion

> ⚠️ This communicates directly with the printer on your LAN using undocumented protocols.  
> Use at your own risk.

----------

## Features

- MQTT communication over TLS

- Implicit FTPS support (port 990)

- Real-time printer status updates

- Print-finished callback support

- File upload with progress reporting

- Timeout-safe FTPS uploads

- No cloud services or Bambu Studio required

----------

## Requirements

### Python Version

- Python 3.8 or newer

## Helper Class

## ImplicitFTP_TLS

Subclass of `ftplib.FTP_TLS` that enables **implicit FTPS**.

Bambu printers require TLS encryption **immediately upon connection** (port 990).  
Python’s default `FTP_TLS` uses explicit FTPS and will not work.

This class:

- Automatically wraps the socket with SSL

- Enables SD card access on Bambu printers

https://gist.github.com/hoogenm/de42e2ef85b38179297a0bba8d60778b

## Main Class

# BambuPrinter

Represents a single Bambu printer and exposes high-level control and monitoring APIs.

----------

## Initialization

### `__init__(ip, access_code, serial)`

Initializes the printer client and prepares MQTT and FTPS connections.

**Parameters**

- **ip** (`str`)  
  Local IP address of the printer  
  Example: `192.168.1.50`

- **access_code** (`str`)  
  8-digit access code found in the printer settings

- **serial** (`str`)  
  Printer serial number

**Example**

```python
printer = BambuPrinter(
    ip="192.168.1.50",
    access_code="12345678",
    serial="01S00A123456789"
)
```

----------

## MQTT Communication

### `connect()`

Connects to the printer’s MQTT broker and starts the background network loop.

- Uses port 8883

- TLS enabled (self-signed certificates accepted)

- Non-blocking

```python
printer.connect()
```

----------

### `disconnect()`

Stops the MQTT background loop and closes the connection.

```python
printer.disconnect()
```

----------

### `enable_debug_listener()`

Subscribes to the printer’s status topic and prints real-time updates, including:

- Print progress percentage

- Nozzle temperature

- Bed temperature

- Printer state

- Current layer number

```python
printer.enable_debug_listener()
```

----------

### `set_on_finish(callback)`

Registers a callback function that is triggered when a print finishes.

**Parameters**

- **callback** (`callable`)  
  A function with no arguments

**Example**

```python
def on_print_done():
    print("Print finished!")

printer.set_on_finish(on_print_done)
```

----------

## Printer Control Commands

### `pause()`

Pauses the currently running print job.

```python
printer.pause()
```

----------

### `stop()`

Immediately stops the active print job.

```python
printer.stop()
```

----------

### `home()`

Homes all printer axes using the G-code command `G28`.

```python
printer.home()
```

----------

### `send_gcode(gcode_line)`

Sends a raw G-code command to the printer.

**Parameters**

- **gcode_line** (`str`)  
  One or more G-code commands

```python
printer.send_gcode("M104 S200")
```

----------

### `blink_light(count=10)`

Blinks the chamber light to visually identify the printer.

**Parameters**

- **count** (`int`, default: 10)  
  Number of on/off toggles

```python
printer.blink_light(6)
```

----------

### `send_gcode_file(gcode_filename)`

Reads a local G-code file and sends its contents directly to the printer.

> ⚠️ Recommended only for small or test files.  
> Large files should be uploaded and printed from the SD card.

```python
printer.send_gcode_file("test.gcode")
```

----------

### `start_print(...)`

Starts a print using a file already present on the printer’s SD card.

**Parameters**

- **filename** (`str`)  
  File name on the SD card

- **bed_levelling** (`bool`, default: False)  
  Run automatic bed leveling

- **flow_cali** (`bool`, default: False)  
  Perform flow calibration

- **vibration_cali** (`bool`, default: False)  
  Perform vibration calibration

- **use_ams** (`bool`, default: False)  
  Enable the AMS system

**Example**

```python
printer.start_print(
    "cube.3mf",
    bed_levelling=True,
    use_ams=True
)
```

----------

## File Management (FTPS)

### `list_files()`

Lists all files on the printer’s SD card.

```python
printer.list_files()
```

----------

### `upload_file(local_path)`

Uploads a file to the printer’s SD card with real-time progress output.

> ⚠️ Known issue: some transfers may hang at 100%.

**Parameters**

- **local_path** (`str`)  
  Path to the local file

```python
printer.upload_file("cube.3mf")
```

----------

### `upload_file_timeout(local_path, timeout=10)`

Uploads a file with socket timeouts to prevent hanging.

**Parameters**

- **local_path** (`str`)  
  Path to the local file

- **timeout** (`int`, default: 10)  
  Socket timeout in seconds

**Returns**

- `True` if upload completed or all bytes were sent

- `False` if upload failed

```python
success = printer.upload_file_timeout("cube.3mf", timeout=15)
```

----------

## Typical Usage Example

```python
printer = BambuPrinter(ip, access_code, serial)

printer.connect()
printer.enable_debug_listener()

printer.upload_file_timeout("part.3mf")
printer.start_print("part.3mf")

printer.disconnect()
```

## Example: Start a Print and Run Commands After Completion

This example demonstrates how to:

- Create a `BambuPrinter` instance

- Start a print from the SD card

- Register a callback that runs **after the print finishes**

- Send G-code once the print is complete

- Exit cleanly\
  There are probably more elegant ways to do this but this is what i came up with.

```python
from printerclass import BambuPrinter
import time

# Create printer instance (example values)
my_a1_mini = BambuPrinter(
    ip="192.168.1.237",
    access_code="48291374",
    serial="01S00A1M23456789"
)

# Flag used to exit the loop once the print is finished
finished = False
# Callback function triggered when the print finishes
def move_when_done():
    global finished

    time.sleep(2)  # small delay after completion
    print("Print complete")

    # Example post-print movement (relative move on X axis)
    my_a1_mini.send_gcode("G91\nG1 X10 F3000\nG90")

    finished = True


# Connect and configure callbacks
my_a1_mini.connect()
my_a1_mini.enable_debug_listener()
my_a1_mini.set_on_finish(move_when_done)

# Start a print already present on the SD card
my_a1_mini.start_print("example_part.gcode.3mf")

# Keep the script alive until the print finishes
while not finished:
    time.sleep(1)

print("Script exiting gracefully.")
my_a1_mini.disconnect()
```

----------

### Notes

- The script **must stay running** for the MQTT finish callback to fire

- The G-code sent in the callback uses:
  
  - `G91` → relative positioning
  
  - `G1 X10 F3000` → move X axis 10mm
  
  - `G90` → return to absolute positioning

- Replace the IP, access code, serial, and filename with your own values
